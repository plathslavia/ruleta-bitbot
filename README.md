# Ruleta BitBot

Ruleta de acciones para BITBOT con historial por sesión, resumen y comandos `!use add` listos para copiar.

Página: https://plathslavia.github.io/ruleta-bitbot/

Las sesiones se guardan en el navegador donde se abre la página. En Ajustes hay botones para exportar e importar una copia de seguridad.
